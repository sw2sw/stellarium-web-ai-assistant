# 讲解、交流与当前时刻推荐

助手版本0.14.0，桥接版本0.11.0，协议版本2。

## 讲解与交流

讲解使用选定天体的引擎快照，区分稳定天文知识、快照解读与下一步观看建议。点击“继续交流”可围绕该天体追问；“问问星空”适用于自由提问。打开窗口不会自动调用模型，发送问题才请求。会话不会自动操作星图；需要执行的动作仍走预览、确认和读回。

AI生成内容仅供参考，可能存在错误。快照不能证明天气、地面遮挡或实际可见性，缺失字段保持未知。免责声明不代替科学核查。

会话保存在当前页面内存中，刷新或关闭页面后消失；发送时，相关历史和星图上下文会交给所选模型处理，服务商的日志与留存政策另行适用。因此不要输入凭据或其他敏感内容。

## 当前时刻推荐

默认按软件所设置的时间与模拟地点，分别为肉眼和小型望远镜目镜观看筛选月球及大行星。程序使用引擎读数和确定性规则筛选；模型负责解释，不是计算引擎的替代品。当前结果不覆盖整晚，也不保证现实天空可见。白天、接近太阳或缺少关键读数的目标采用保守排除；禁止把太阳当作直接目视目标。

新的“现在呢？”请求刷新当前依据；针对“刚才”的追问保留原推荐的时间与地点。查看推荐目标由用户点击触发，推荐计算本身不移动天空。

## 可选目标文件

可在助手资源目录提供同源`curated-targets.json`扩展参考目标。格式参见`../tests/fixtures/sky-targets/curated-targets.json`（测试夹具不是正式推荐星表）。文件不存在或无效时保留内置推荐。外部元数据不能覆盖引擎动态读数，也不能冒用内置目标身份。

## 已知限制

模型可能产生事实错误、无依据的观测建议或空回复；成功响应不代表科学结论正确。高质量知识库和关系图谱属于后续增强方向，本版尚未接入。月相读数主要表示照亮比例，不提供完整盈亏方位/月龄解释。全夜最佳时段计算尚未实现。
