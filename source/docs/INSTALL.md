# 安装、更新与卸载

以下命令从仓库 `source/` 目录运行。安装器操作本地文件，不联网、不调用模型，也不启动对外服务。

## 前提与备份

- Node.js 18+，以及已经构建好的兼容 Stellarium Web 站点目录，包含 `index.html`、引擎资源和星图数据。
- 先备份站点与现有助手资源；不要把服务器 AI 的配置、身份或额度数据当作前端安装产物覆盖。
- 使用站点实际运行用户检查入口和资源可读权限；容器环境还需核对挂载权限与安全标签。
- 浏览器应通过 HTTP 或 HTTPS 访问站点，不使用 `file://`。

没有现成宿主时先阅读[构建指南](UPSTREAM-BUILD.md)。本源码仓库不包含完整宿主或整站运行包。

## 只读检查与安装

```bash
node install/install.mjs --host /path/to/dist --check
node install/install.mjs --host /path/to/dist
```

安装器检查[宿主登记表](../install/known-hosts.json)、首页入口标记与助手目录所有权：

| 宿主结果 | 默认行为 |
|---|---|
| `verified` | 与登记构建相符，可继续安装。 |
| `variant` | 入口存在差异，默认拒绝；先核对差异及兼容性，必要时显式使用 `--allow-variant`。 |
| `unknown` | 无法识别，默认拒绝；`--allow-unknown-host` 是显式放宽检查，不是兼容性保证。 |

入口标记重复、被手动修改，或助手目录不是本安装器创建时，安装器会拒绝直接覆盖。不要把 `--force` 当作常规安装参数。

正常安装在首页添加助手加载标记，发布到 `ai-assistant/`，并记录 `.install.json`。原入口备份位于 `.swe-backup/`；应保护该目录，不将状态文件和备份作为公开源码提交。

## 更新助手

```bash
node install/install.mjs --host /path/to/dist --update /path/to/new-assistant
```

更新包的 `manifest.json`、协议和全部资源引用会在发布前检查。当前参考资源包括 `naming-reference.js` 和 `sky-targets.js`；实际集合以 manifest 为准。入口、样式和参考文件必须是可发布的顶层文件，不能指向隐藏文件、Markdown、子目录或上级路径。

更新助手不要求重新编译宿主引擎。安装器仍会检查宿主与登记值、入口标记及已安装状态；宿主被重建或替换后，应先重新核对身份，而不是绕过检查继续更新。

资源缓存查询参数 `assetQuery` 根据内容生成，因此同版本号下的内容修改也应更新缓存标识。对外静态服务应提供适当缓存策略，避免旧 manifest 与新脚本混用。

## 失败恢复与权限

资源先写入暂存目录，检查后换名发布；入口通过临时文件替换，并保留原入口权限位。失败时安装器尝试恢复操作前状态，只清理本次创建的临时路径。

**不要把非零退出或错误文本等同于已完整回滚。** 如果回执指出入口、旧目录或新目录未能恢复，应检查 `.swe-backup/`、`ai-assistant/` 与提示中指向的暂存/旧目录，确认实际字节后再处理。

发布成功后，清理旧目录失败可能只产生 `WARNING`；这与新版本发布失败不同。不要仅根据残留目录判断当前运行版本。

## 状态与卸载

```bash
node install/install.mjs --host /path/to/dist --status
node install/install.mjs --host /path/to/dist --uninstall
```

卸载移除入口标记，并删除安装状态登记且哈希仍匹配的助手资源。用户新增文件或被手动修改的文件可能保留并产生提示；非空目录不应被当成可安全递归删除的目录。

## 安装后核对

1. 以实际服务用户确认 `index.html` 和助手资源可读。
2. 从站点 HTTP 入口读取 manifest，核对助手版本、协议和缓存标识。
3. 打开星图，确认原站点渲染正常、助手可加载并能读取引擎状态。
4. 验证升级没有改动不应更新的引擎文件、服务器配置或身份/额度数据。

安装器与故障隔离回归入口位于 `tests/installer/safety.mjs` 和 `tests/e2e/hotswap.mjs`，应在独立可写的测试副本中运行，不使用生产数据目录。

## 安全与网络边界

- 助手以同源脚本运行，能访问页面与引擎，**不是沙箱**。
- AI功能会向已配置的模型端点或同源服务发出请求，发送范围见[项目隐私说明](../../README.md)和[服务器AI指南](SERVER-AI.md)。
- 安装器不写入模型凭据；模型配置与服务端身份、额度存储应单独保护。
- `tools/serve.mjs` 仅用于本机预览，没有认证或 TLS。对外部署应使用受控的静态服务器和适当的反向代理，不将本地工具直接开放到网络。
