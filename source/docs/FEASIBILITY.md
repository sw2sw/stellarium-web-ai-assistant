# 宿主集成架构与适配边界

本文说明助手与 Stellarium Web 的集成方式。功能与使用入口见[项目说明](../../README.md)，桥接接口见[能力参考](API-CAPABILITIES.md)。

## 组件关系

```text
Stellarium Web 静态站点
  └─ index.html 中的助手加载入口
       └─ ai-assistant/loader.js
            ├─ 连接页面已有的星图引擎实例
            ├─ 读取 manifest.json 与加载参考资源
            └─ 加载 assistant.js / assistant.css
                 ├─ 引擎状态、命令预览与执行读回
                 ├─ 讲解、多轮交流、月球与行星推荐
                 └─ 客户端模型端点或可选同源 AI 服务
```

助手复用宿主引擎，不创建第二个 WASM 实例。助手资源可单独更新；无需为了修改助手界面或提示词而重编宿主。

## 宿主适配

- 适配器位于 `packages/host-adapter/loader.js`；上游版本由[锁定清单](../upstream/LOCK.md)指定。
- 当前适配依赖 Vue 2 宿主能够提供已有引擎实例。上游框架或初始化方式发生变化时，必须重新评估适配，不承诺任意版本兼容。
- 宿主补丁分别处理 Vue 版本范围、界面语言钩子和外链字体；构建步骤见[构建指南](UPSTREAM-BUILD.md)。
- 安装器核对宿主指纹、入口标记和已安装资源，默认拒绝未知或发生未确认变化的宿主。详见[安装指南](INSTALL.md)。

## 状态与模型的职责

引擎负责时间、地点、视场、天体位置和图层等软件状态。模型负责语言理解和文字生成，不能把模型文本当作引擎实际读数。

控制请求先生成受限命令提案，由用户确认后执行，并读取引擎状态验证结果；交流和讲解不等同于执行控制。推荐使用软件内设定的时间、地点和引擎读数，不默认代表用户现实所在地的天空。

AI生成内容仅供参考，可能存在错误。模型服务不可用时，原星图的基本运行不应依赖模型服务恢复。

## 运行与数据边界

- 助手是同源脚本，不是安全沙箱；它能够访问页面和引擎。
- AI请求会向所选服务发送必要上下文；客户端、同源代理与提供商的数据处理边界见[项目说明](../../README.md)和[服务端指南](SERVER-AI.md)。
- 任意天体查询、名称消歧和鼠标拾取能力受引擎接口与所加载数据限制，不能仅凭模型回答宣布目标已找到或动作已完成。
- 本仓库不包含完整上游树或整站运行包；源码与许可的未完成项见[对应源码范围](../../release/SOURCE-ACCESS.md)。
