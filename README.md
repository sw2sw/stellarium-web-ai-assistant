# Stellarium Web AI 教学助手

为兼容的 [Stellarium Web](https://github.com/Stellarium/stellarium-web-engine) 星图添加天体讲解、多轮交流和观测目标推荐。助手可独立更新，不必每次重编星图引擎。

**版本：助手0.14.0 · 桥接0.11.0 · 协议2**

> **AI生成内容仅供参考，可能存在错误。** 天体位置、时间及其他动态数值应以星图引擎读回为准；科学结论和实际观测建议需另行核实。软件模拟不代表现实天气、地面遮挡或实际可见性。请勿通过普通望远镜或双筒望远镜直接观察太阳。

## 功能

- **天体讲解**：结合选中天体的快照，说明它是什么、当前读数意味着什么，以及下一步怎么看。
- **继续交流**：围绕已讲解的天体追问，或通过“问问星空”提出问题。打开窗口不会自动调用模型。
- **当前时刻推荐**：按软件设置的时间与模拟地点，为肉眼和小型望远镜目镜观看筛选月球及大行星；提供可选的外置参考目标文件接口。
- **受控星图操作**：模型提出操作建议，本地白名单校验后由用户预览、确认；执行后读取引擎状态验证结果。
- **两种模型来源**：浏览器自定义OpenAI兼容端点，或部署者配置的同源服务器AI。两种来源不会自动互相回退。
- **中英文界面**：界面提示随所选语言切换。

推荐针对**当前模拟时刻**，不是整晚最佳时段预测。计算推荐本身不会改变星图画面。

## 安装到已有星图站点

前提：准备与版本锁兼容、已构建的Stellarium Web站点目录。建议使用Node.js 24运行安装和服务脚本。浏览器需支持宿主引擎要求的WebGL/WASM，并通过HTTP提供站点，不能直接打开`file://`页面。

从仓库根目录运行：

```bash
# 将路径替换为自己的兼容星图站点目录；操作前先备份
node source/install/install.mjs --host /path/to/stellarium-dist

# 安装后检查
node source/install/install.mjs --host /path/to/stellarium-dist --check
```

安装器会识别宿主、备份入口，并更新助手资源。宿主不匹配时默认拒绝；不要为绕过未知差异随意使用强制参数。更新、卸载与回滚步骤见[安装说明](source/docs/INSTALL.md)。

没有现成宿主时，先阅读[上游构建说明](source/docs/UPSTREAM-BUILD.md)和[对应源码范围](release/SOURCE-ACCESS.md)。本项目源码包不是完整对应源码交付，也不等同于完整上游树或完整整站部署包。

## 配置模型

### 浏览器自定义模式

在助手设置中填写兼容端点与模型标识，需要时填写API Key。请求由浏览器发往所选端点，端点需要允许该网页来源访问。部署者也可自行提供受控同源代理；不要把密钥写进静态网页或提交到仓库。

### 服务器模式

由部署者配置`ai-service`，统一管理上游、认证和持久额度。浏览器通过同源服务请求模型，无需获得上游Key。管理口令、课堂口令、模型凭据及可写数据目录均应放在Web公开目录之外，首次配置前保留关闭状态。

详见[服务器AI说明](source/docs/SERVER-AI.md)。建议通过HTTPS或可信的加密网络访问；服务端Key不会显示给浏览器，但请求内容仍会发送至部署者配置的模型服务。

## 隐私与模型边界

- 对话保存在当前页面内存中，刷新或关闭页面后消失；本项目不另建聊天历史存储。
- **发送时，相关对话、问题和星图上下文会交给所选AI服务处理。** 服务商或部署环境可能保留请求日志，适用其自身政策。页面内存存储不代表数据从未传出浏览器。
- 不要在提问中输入API Key、口令、个人身份资料或其他敏感内容。
- 自定义模式的配置是否记忆由界面选项决定；不要在公共或共享设备上保存凭据。
- 宿主星图和所选端点可能请求外部资源；本项目不承诺完全离线或零外部请求。

## 已知限制

- 模型可能出现事实错误、无依据的推断、空回复或延迟；HTTP成功不代表科学内容正确。免责声明不能替代核查。
- 模型调用可能消耗费用或额度；停止、关闭窗口或网络中断不保证上游已经停止计费。结果不确定时不要自动重复发送。
- 当前没有接入高质量知识库或知识图谱；这些属于后续增强方向，不是本版已实现的能力。
- 推荐不评估完整天气、地面遮挡及个人设备条件，也不覆盖整晚最佳观测时段。
- 外置目标测试夹具仅用于验证接口，不是正式观测目标库。
- 宿主版本兼容性受[版本锁](source/upstream/LOCK.md)约束，不保证适配任意Stellarium Web版本。
